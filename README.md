# 🐍 Snake for Windows - גרסת נוקיה 225

פרויקט זה הוא שחזור של משחק הסנייק (Snake) הקלאסי והנוסטלגי ממכשירי נוקיה הישנים, נכתב לחלוטין בפייתון בעזרת ספריית **Pygame**. המשחק מותאם לשפה העברית, פועל לחלוטין באופליין (ללא צורך באינטרנט), וכולל שמירת שיאים מקומית.

## ✨ פיצ'רים מרכזיים
* **תפריט בעברית:** התחלת משחק, יציאה והגדרות.
* **הגדרות מהירות:** בחירה בין רמות קושי (קל, רגיל, קשה).
* **קושי מתקדם:** ככל שהנחש גדל, המשחק מהיר יותר בהדרגה (עד תקרה סבירה).
* **השהיה:** לחיצה על `P` באמצע משחק עוצרת ומחזירה אתכם בלחיצה חוזרת.
* **מערכת שיאים:** המשחק שומר את שיא הנקודות בקובץ מקומי (`high_score.json`), ומציג אותו גם בתפריט הראשי.
* **מעבר קירות:** כניסה לקיר אחד תוציא את הנחש מהצד השני.
* **סגנון רטרו:** צבעים בהשראת המסכים הישנים.

## 🎮 בקרות
| מקש | פעולה |
|---|---|
| חצים | שינוי כיוון |
| `P` | השהיה / המשך |
| `C` (במסך "נפסלת") | שחק שוב |
| `Q` (במסך "נפסלת") | חזרה לתפריט |

## 🚀 איך מריצים את המשחק?

1. ודא שמותקן אצלך [Python 3](https://www.python.org/downloads/).
2. הורד או שכפל (Clone) את התיקייה למחשב.
3. פתח את שורת הפקודה (CMD) בתיקיית המשחק, והתקן את התלויות באמצעות הפקודה:
   ```bash
   pip install -r requirements.txt
   ```
4. הפעל את המשחק באמצעות הפקודה:
   ```bash
   python main.py
   ```

## 🔄 עדכון אוטומטי
המשחק כולל מנגנון עדכון פנימי מול המאגר [YSmauas/Snake-for-Windows](https://github.com/YSmauas/Snake-for-Windows). אם יצאה גרסה חדשה למשחק בגיטהאב, פשוט הפעל את הקובץ `update.bat` (או הרץ `python update.py`), והמשחק ימשוך את העדכון האחרון אוטומטית (פעולה זו בלבד דורשת חיבור לאינטרנט).

> ⚠️ מנגנון העדכון עובד רק כשמריצים את `main.py` כסקריפט פייתון. אם קימפלתם exe (ראו למטה), עדכון דורש קימפול מחדש והחלפת קובץ ה-exe.

## 🛠️ קימפול ל-exe (קובץ הפעלה עצמאי)

כדי שאפשר יהיה להריץ את המשחק במחשב Windows בלי להתקין פייתון:

1. התקינו את PyInstaller (כלול כבר ב-`requirements.txt`):
   ```bash
   pip install -r requirements.txt
   ```
2. הריצו מתיקיית הפרויקט:
   ```bash
   pyinstaller --onefile --windowed --name Snake main.py
   ```
3. קובץ ה-exe הסופי יימצא בתיקיית `dist/Snake.exe`. קובץ השיא (`high_score.json`) יישמר אוטומטית באותה תיקייה כמו ה-exe.

**הערה:** ייתכן שתוכנת אנטי-וירוס (כולל Windows Defender) תסמן את קובץ ה-exe באזהרת "False Positive" - זו תופעה נפוצה בקבצים שנוצרו ע"י PyInstaller ולא מעידה על בעיה בקוד עצמו.

## 📂 מבנה הקבצים
* `main.py` - הלוגיקה המרכזית של המשחק.
* `update.py` & `update.bat` - מנגנון העדכון האוטומטי.
* `requirements.txt` - רשימת הספריות החיצוניות הנדרשות (כולל PyInstaller לקימפול).
* `high_score.json` - ייווצר אוטומטית לשמירת השיא (לא נכלל בגיט).
* `.gitignore` - קבצים שיש להתעלם מהם בגרסאות הגיט (כולל תיקיות build/dist מקימפול).
