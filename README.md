# 🐍 Snake for Windows - גרסת נוקיה 225

פרויקט זה הוא שחזור של משחק הסנייק (Snake) הקלאסי והנוסטלגי ממכשירי נוקיה הישנים, נכתב לחלוטין בפייתון בעזרת ספריית **Pygame**. המשחק מותאם לשפה העברית, פועל לחלוטין באופליין (ללא צורך באינטרנט), וכולל שמירת שיאים מקומית, אפקטי קול, ועיצוב מודרני מסביב ללוח משחק רטרו קלאסי.

## ✨ פיצ'רים מרכזיים

* **תפריט בעברית** בעיצוב מודרני: התחלת משחק, יציאה, הגדרות ועדכון אוטומטי.
* **הגדרות מהירות:** בחירה בין רמות קושי (קל, רגיל, קשה).
* **קושי מתקדם:** ככל שהנחש גדל, המשחק מהיר יותר בהדרגה (עד תקרה סבירה).
* **תפוח מוזהב מיוחד 🍏:** מופיע מדי פעם, נעלם אחרי 5 שניות - ככל שתופסים אותו מהר יותר, מקבלים יותר נקודות.
* **אפקטי קול:** נגיסה באכילת תפוח, ביפ בעליית קושי, ו"באזז" בסיום משחק.
* **אייקון מותאם** לקובץ ה-exe ולחלון המשחק.
* **השהיה:** לחיצה על `P` באמצע משחק עוצרת ומחזירה אתכם בלחיצה חוזרת.
* **מערכת שיאים:** המשחק שומר את שיא הנקודות בקובץ מקומי (`high_score.json`), ומציג אותו גם בתפריט הראשי.
* **מעבר קירות:** כניסה לקיר אחד תוציא את הנחש מהצד השני.
* **עיצוב היברידי:** לוח המשחק עצמו בסגנון רטרו-נוקיה קלאסי (ירוק וגריד), ואילו כל מה שסביבו (שורת סטטוס, תפריטים, שוליים) בעיצוב מודרני כהה - כך שהממשק לא "בולע" משבצות משחק.
* **עדכון אוטומטי מובנה:** גם בגרסת ה-exe המקומפלת - המשחק בודק מול Releases בגיטהאב ומעדכן את עצמו בלחיצת כפתור.

## 🎮 בקרות

| מקש | פעולה |

| חצים | שינוי כיוון |
| `P` | השהיה / המשך |
| `C` (במסך "נפסלת") | שחק שוב |
| `Q` (במסך "נפסלת") | חזרה לתפריט |

## 🚀 איך מריצים את המשחק?

1. ודא שמותקן אצלך [Python 3](https://www.python.org/downloads/).
2. הורד או שכפל (Clone) את התיקייה למחשב.
3. פתח את שורת הפקודה (CMD) בתיקיית המשחק, והתקן את התלויות באמצעות הפקודה:
   ```bash
   pip install -r requirements.txt
   ```
4. הפעל את המשחק באמצעות הפקודה:
   ```bash
   python main.py
   ```

## 🔄 עדכון אוטומטי

**בגרסת ה-exe:** המשחק בודק אוטומטית מול ה-[Release](https://github.com/YSmauas/Snake-for-Windows/releases) האחרון בגיטהאב. אם יש גרסה חדשה, תופיע בתפריט הראשי שורה "לחצו לעדכון" - לחיצה על `4` מורידה את ה-exe החדש ומחליפה את עצמה אוטומטית (המשחק ייסגר וייפתח מחדש עם הגרסה המעודכנת).

**בגרסת קוד המקור:** הפעילו את `update.bat` (או `python update.py`) כדי למשוך את `main.py` העדכני מה-Release האחרון.

> ⚠️ שני המנגנונים דורשים חיבור לאינטרנט, ומזהים גרסה חדשה **רק** אם התגית (tag) של ה-Release בגיטהאב היא Semantic Version תקין בפורמט `vX.Y.Z` (למשל `v1.0.1`), ואינה מסומנת כ-Pre-release.

## 🛠️ קימפול ל-exe (קובץ הפעלה עצמאי)

כדי שאפשר יהיה להריץ את המשחק במחשב Windows בלי להתקין פייתון:

1. התקינו את PyInstaller (כלול כבר ב-`requirements.txt`):
   ```bash
   pip install -r requirements.txt
   ```
2. הריצו מתיקיית הפרויקט:
   ```bash
   pyinstaller --onefile --windowed --name Snake --icon=assets/icon.ico --add-data "assets;assets" main.py
   ```
3. קובץ ה-exe הסופי יימצא בתיקיית `dist/Snake.exe`. קובץ השיא (`high_score.json`) יישמר אוטומטית באותה תיקייה כמו ה-exe.

**קימפול אוטומטי בענן:** המאגר כולל GitHub Actions workflow (`.github/workflows/build-exe.yml`) שמריץ את הקימפול הזה בשרתי גיטהאב בכל push, כך שאפשר לקבל exe מוכן בלי מחשב משלכם - ראו לשונית **Actions** במאגר.

**הערה:** ייתכן שתוכנת אנטי-וירוס (כולל Windows Defender) תסמן את קובץ ה-exe באזהרת "False Positive" - זו תופעה נפוצה בקבצים שנוצרו ע"י PyInstaller ולא מעידה על בעיה בקוד עצמו.

## 📂 מבנה הקבצים

* `main.py` - הלוגיקה המרכזית של המשחק (תנועה, ציור, קול, עדכון אוטומטי).
* `assets/` - אייקון (`icon.ico` / `icon.png`) וקבצי הצלילים (`crunch.wav`, `gameover.wav`, `levelup.wav`, `special.wav`).
* `update.py` & `update.bat` - מנגנון העדכון האוטומטי לגרסת קוד המקור.
* `requirements.txt` - רשימת הספריות החיצוניות הנדרשות (כולל PyInstaller לקימפול).
* `.github/workflows/build-exe.yml` - קימפול exe אוטומטי בענן דרך GitHub Actions.
* `high_score.json` - ייווצר אוטומטית לשמירת השיא (לא נכלל בגיט).
* `.gitignore` - קבצים שיש להתעלם מהם בגרסאות הגיט (כולל תיקיות build/dist מקימפול).

## 🔢 גרסאות

הגרסה הנוכחית של הקוד מוגדרת בקבוע `VERSION` בראש `main.py`. בכל פעם שיוצרים Release חדש בגיטהאב, יש לוודא ששתי אלה מסונכרנות:
1. `VERSION` בקוד (למשל `"1.0.1"`)
2. תגית ה-Release בגיטהאב (למשל `v1.0.1`) - **עם `v` בהתחלה**

אחרת מנגנון העדכון האוטומטי לא יזהה נכון שיש גרסה חדשה.
